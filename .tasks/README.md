# Israel Kitchen - Task Management

This directory is managed by TaskMaster AI for project task tracking.

## Usage

Run TaskMaster AI:
```bash
npm run tasks
```

Or use directly:
```bash
npx task-master-ai
```

## Features

- ✅ Task creation and management
- 📊 Priority levels and categorization
- 🔔 Due dates and reminders
- 📝 Task notes and descriptions
- 🔄 Integration with GitHub and Vercel
